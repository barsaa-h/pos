💳 PAX A930 Терминал тохиргоо {% if terminal_configured %} Идэвхтэй {% else %} Тохиргоо хийгдээгүй {% endif %}

PAX A930 болон бусад TCP/IP сүлжээний төлбөрийн терминалын холболтын тохиргоо. Терминалын TCP Server режимийг идэвхжүүлээд, дотоод сүлжээний IP хаягийг оруулна уу.

⚠️ PAX A930 холбох заавар:
1. PAX A930 дээрээ QuickPOS → Тохиргоо → TCP Server-ийг ON болгоно
2. PAX-ны IP хаягийг энд бичнэ (PAX дээр: Тохиргоо → Сүлжээ → Wi-Fi/LAN)
3. Порт: 10009 (стандарт, өөрчлөх шаардлагагүй)
4. POS компьютер болон PAX нэг дотоод сүлжээнд холбогдсон эсэхийг шалгана уу
5. Доорх "Холболт шалгах" товчоор холболтоо баталгаажуулна уу
