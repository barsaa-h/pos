# Миний дэлгүүр — POS / My Store POS

Борлуулалт, нөөц, тайлан, хэвлэгч болон eBarimt-ийн нэгдсэн систем.
Монголын хүнсний дэлгүүрүүдэд зориулсан **production-ready** ПОС (POS) програм.

**Real desktop app** — Програмын дүрс дээр double-click хийхэд хоёр native цонх зэрэг нээгдэнэ:
* **Кассчны цонх** — Бараа, сагс, төлбөр, гарын түргэн товчлуурууд
* **Үйлчлүүлэгчийн дэлгэц** — Худалдан авагчид харагдах хоёр дахь дэлгэц

No browser, no `localhost`, no command line needed.
Вэб хөтөч, `localhost`, эсвэл тушаалын мөр (command line) ашиглах шаардлагагүй.

## Эхлүүлэх / Quick Start

### Ubuntu (Linux)

```bash
cd ~/pos
./ubuntu/install.sh
# Дараа нь Desktop дээрх "Миний дэлгүүр" дүрс дээр давхар дарж ажиллуулна
```

`ubuntu/install.sh` скрипт юу хийх вэ? / What it does:
1. Python 3 байгаа эсэхийг шалгана / Checks Python 3
2. Virtual environment (venv) үүсгэнэ / Creates venv
3. Шаардлагатай бүх хамаарлыг суулгана / Installs all dependencies (Flask, pywebview, bcrypt, python-escpos, ebarimt-pos-sdk, pyserial, screeninfo)
4. Өгөгдлийн санг үүсгэж, тохируулна / Initializes database
5. Desktop shortcut (Ажиллуулах дүрс) үүсгэнэ / Creates desktop shortcut
6. Програмыг систем асах үед автоматаар ажиллахаар тохируулна / Sets up auto-start on login
7. systemd үйлчилгээ суулгахыг сануулна / Asks to install systemd service

### Windows

```cmd
windows\start.bat
```

`windows/start.bat` скрипт юу хийх вэ? / What it does:
1. Системээс Python хайна (python, python3, py) / Finds Python
2. venv үүсгэнэ / Creates virtual environment
3. Шаардлагатай хамаарлуудыг суулгана / Installs dependencies
4. Өгөгдлийн санг үүсгэнэ / Creates database
5. log, backup, uploads хавтаснуудыг үүсгэнэ / Creates log/backup/uploads dirs
6. `windows/desktop.py` хувилбарыг эхлүүлнэ / Starts the desktop app

### PowerShell (Windows, Unicode-friendly)

```powershell
windows\start.ps1
```

### Docker (Headless горим, зөвхөн вэб хандалт / web-only)

```bash
docker build -t pos .
docker run -d -p 8765:8765 \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/backups:/app/backups \
  --restart unless-stopped \
  --name minii-delguur pos
# Хөтөч дээр http://localhost:8765 хаягаар нээнэ / Open in browser
```

### Терминалаас (Тушаалын мөр) ажиллуулах / From Terminal

```bash
python3 desktop.py          # Үйлдлийн системийг автоматаар танина / Auto-detects OS
source venv/bin/activate && python3 app.py  # Зөвхөн вэб горимоор ажиллуулах / web only
```

Бүх миграц `migrate_db()` функц дотор автоматаар хийгддэг бөгөөд олон дахин дуудахад ямар нэгэн алдаа үүсгэхгүй (Idempotent):

1. `admin_password_hash` тохиргоо нэмэх (анх удаа үүсэхэд хоосон байна)
2. `sales` хүснэгтийн `cashier_id`-ийг nullable болгох
3. `sale_items` хүснэгтийн `quantity` CHECK constraint-ийг устгах
4. `sales` хүснэгтэд `return_of_sale_id` багана нэмэх
5. `sales` хүснэгтэд `ebarimt_lottery` багана нэмэх
6. `products` хүснэгтэд `cost_price` болон `expiry_date` багана нэмэх
7. `products` хүснэгтэд `image_url` болон `supplier_id` багана нэмэх
8. `suppliers` хүснэгтийг шинээр үүсгэх
9. `sales` хүснэгтийн CHECK constraint-д `qr` төлбөрийн төрлийг нэмэх
10. `cash_drawer_log` хүснэгтийг үүсгэх
11. `idempotency_keys` хүснэгтийг үүсгэх
12. `categories` хүснэгтийг үүсгэж, анхны өгөгдлийг оруулах (seed)
13. `shifts` хүснэгтийг үүсгэх (шинэ)

## Тоног төхөөрөмж / Hardware Setup

### USB Баркод сканнер / USB Barcode Scanner

Ямар нэгэн нэмэлт драйвер шаардлагагүй, USB портонд залгахад шууд ажиллана. Сканнер нь уншсан цифрүүдийн араас автоматаар Enter товчлуурыг илгээдэг HID гар (keyboard) горимоор ажиллах ёстой. Кассын дэлгэц дээр баркод оруулах талбар үргэлж автоматаар фокустай байна.

### USB Дулааны хэвлэгч / USB Thermal Printer (80mm)

**Linux (Ubuntu) дээр тохируулах:**
```bash
# Хэвлэгч холбогдсон портыг шалгах
ls /dev/usb/lp*
# Жишээ гаралт: /dev/usb/lp0

# Тухайн хэрэглэгчийг lp бүлэгт нэмж эрх олгох
sudo usermod -a -G lp $USER
# Системээс гарч (Log out) буцаж нэвтрэх

# Портын унших, бичих эрхийг бүрэн нээх
sudo chmod 666 /dev/usb/lp0
```

**Windows дээр тохируулах:**
- Хэвлэгчийг USB портоор холбоход автоматаар Virtual COM порт үүснэ
- Device Manager → Ports (COM & LPT) хэсгээс ямар порт дээр сууж байгааг шалгана
- Програмын Auto-detect систем нь `serial.tools.list_ports` ашиглан "thermal", "receipt", "ESC/POS" гэсэн нэртэй портуудыг автоматаар хайна
- Олдохгүй бол `COM3` портыг үндсэн утгаар авна

**Програм дахь тохиргоо:**
- Системийн Тохиргоо → Хэвлэгчийн порт хэсэгт гараар тохируулж болно
- Жишээ нь: Linux дээр `/dev/usb/lp0`, Windows дээр `COM3`

### Банкны картын терминал / Bank Card Terminal

**Стандалон (Байгууллагаас тусдаа) горим** — Одоогоор банкны терминал ПОС програмтай шууд кодоор холбогдохгүй.

1. Кассчин төлбөр хийх үед "Картаар төлөх" товчийг дарна
2. Дэлгэц дээр гарсан нийт дүнг банкны ПОС төхөөрөмж дээр гараар шивж үйлчлүүлэгчээр картаа уншуулахыг хүснэ
3. Гүйлгээ амжилттай болж банкны ПОС-оос баримт хэвлэгдсэний дараа кассчин програм дээр "Баталгаажуулах" товч дарна

### Хоёр дэлгэц ашиглах / Dual Monitors (Recommended)

- **Кассчны дэлгэц**: Үндсэн дэлгэц (ПОС-ын борлуулалтын үндсэн цонх ажиллана)

- Хэрэв автомат илрүүлэлт ажиллахгүй бол цонхыг гараар хоёр дахь дэлгэц рүү чирч байрлуулах ба дараагийн удаа байрлалыг санах болно

## Суулгах заавар / Installation

### Ubuntu систем дээр — Бүрэн автомат суулгац

```bash
cd ~/pos
./ubuntu/install.sh
```

`ubuntu/install.sh` скриптийн хийх алхмууд:
1. Python 3 систем дээр байгаа эсэхийг шалгана
2. Native цонх нээхэд зориулсан `libwebkit2gtk-4.1` суулгаагүй бол суулгахыг сануулна
3. Python-ий тусгаарлагдсан орчин үүсгэнэ (`python3 -m venv venv`)
4. `pip install -r requirements.txt` хамаарлуудыг суулгана
5. Өгөгдлийн санг анхлан үүсгэнэ (`db.init_db()`)
6. Шаардлагатай `logs/`, `backups/`, `static/uploads/` хавтаснуудыг үүсгэнэ
7. Дэлгэц дээр шууд ажиллуулах shortcut үүсгэнэ (`~/Desktop/Миний_дэлгүүр.desktop`)
8. Автомат асах системд бүртгэнэ (`~/.config/autostart/`)
9. Шаардлагатай скриптүүдэд ажиллуулах эрх (chmod) өгнө
10. Background-д тасралтгүй ажиллуулах systemd үйлчилгээг суулгахыг санал болгоно

### Ubuntu систем дээр — Гараар суулгах


## eBarimt тохиргоо / eBarimt

eBarimt (Монгол Улсын Татварын Ерөнхий Газрын Цахим Төлбөрийн Баримтын Систем) интеграцийн ажиллагаа.

### Бүртгүүлэх, эрх авах алхмууд

1. [ebarimt.mn](https://ebarimt.mn) системд дэлгүүрийн харилцагч хэлбэрээр бүртгүүлсэн байх
2. Татварын албанаас ПОС програм ажиллуулах дараах өгөгдлүүдийг (Credentials) авна:
   - **API URL** — eBarimt-ийн локал бэлтгэсэн серверийн хаяг
   - **Merchant TIN** — Танай дэлгүүрийн Татвар Төлөгчийн Дугаар (Регистр)
   - **TTD (POS №)** — Тухайн кассанд олгосон ПОС төхөөрөмжийн дугаар
   - **Branch ID** — Салбарын дугаар код
3. Эдгээр мэдээллийг ПОС програмын Тохиргоо → eBarimt тохиргоо хэсэгт оруулж хадгална

### Системийн ажиллагааны логик

- Борлуулалт амжилттай хийгдэж дуусмагц систем цаанаа eBarimt API-руу баримтын өгөгдлийг автоматаар илгээнэ
- **Амжилттай холбогдвол**: `ebarimt_status=sent` төлөвтэй болж, татварын системээс ирсэн дахин давтагдашгүй Баримтын ID, QR код, сугалааны дугаарыг өгөгдлийн сандаа хадгалж, чек дээр хэвлэнэ
- **Интернэт эсвэл татварын сервер унасан үед**: Гүйлгээг зогсоохгүй, `ebarimt_status=failed` төлөвтэйгөөр борлуулалтыг амжилттай дуусгана
- Програм дараагийн удаа асах эсвэл кассчин гараар "Дахин илгээх" товч дарах үед илгээгдээгүй үлдсэн (failed/pending) бүх баримтуудыг татварын сервер рүү нөхөж илгээнэ
- Барааны буцаалт (Return) хийх үед татварын хуулийн дагуу eBarimt шууд илгээгдэхгүй, төлөв нь `skipped` болно

### Ашигласан албан ёсны сан / SDK

- `ebarimt-pos-sdk>=0.3`
- Иргэдэд олгох `B2C_RECEIPT` баримтын төрөл болон `CASH`, `PAYMENT_CARD` төлбөрийн хэлбэрүүдийг бүрэн дэмжсэн
- `EbarimtRestClient` + `CreateReceiptRequest`, `SubReceipt`, `Item`, `Payment` моделиуд
- Татварын төрөл: `VAT_ABLE` (НӨАТ ногдуулдаг)

## Нөөц хуулбар / Backup

### Автомат нөөцлөлт (Automatic Backup)

- Өдөр бүрийн хамгийн анхны борлуулалт хийгдэх үед систем цаанаа `check_and_backup()` функцийг ажиллуулна
- Одоогийн баазыг `backups/pos_YYYY-MM-DD.db` нэрээр хавтаст хуулбарлан хадгална
- Дискний зайг хэмнэх үүднээс 30 хоногоос дээш хугацаатай хуучин нөөц файлуудыг автоматаар устгаж цэвэрлэнэ

### Гараар нөөцлөх болон Сэргээх (Manual Backup & Restore)

```bash
# Гараар шууд нөөц хуулбар үүсгэх (Linux)
cp pos.db backups/pos_manual_$(date +%Y-%m-%d).db

# Өмнөх нөөцөөс баазыг буцаан сэргээх
cp backups/pos_2026-01-15.db pos.db
```

### Тохиргооны дэлгэцээс

Системийн Тохиргоо → "Гар аргаар нөөц хуулбар хийх" товчийг дарахад тухайн цаг үеийн баазыг шууд хадгална.

## Ээлжийн хаалт / Z-Report (Shift)

### Системийн ажиллагааны горим

1. Өдрийн эхний борлуулалт хийгдэх үед систем цаанаа `ensure_shift_open()` функцийг ажиллуулж, тухайн өдрийн кассын шинэ ээлжийг автоматаар нээнэ
2. Өдрийн турш хийгдсэн бүх борлуулалт, картын гүйлгээ, бэлэн мөнгөний хөдөлгөөнүүд тухайн нээлттэй ээлжийн ID-д бүртгэгдэнэ
3. Өдрийн төгсгөлд кассчин ажлаа хүлээлгэж өгөх эсвэл дэлгүүр хаах үед кассанд байгаа бэлэн мөнгөө тоолж оруулснаар ээлжийг хаана:

```bash
# POST /api/shift/close хүсэлтийн жишээ:
{
  "actual_cash": 245000
}
```

Систем тооцоололт хийж, кассчинд дараах ээлжийн хаалтын Z-Тайланг буцааж харуулна:

```
Ээлж нээх үеийн мөнгө (opening_balance):  50,000₮
+ Бэлэн орлого (cash_sales):              195,000₮
---------------------------------------------------
Тооцоот үлдэгдэл (expected_cash):         245,000₮
Тоолсон бэлэн мөнгө (actual_cash):        245,000₮
---------------------------------------------------
Зөрүү (difference):                             0₮  ← 0 бол касс дутагдалгүй!

Карт борлуулалт:      120,000₮  (card_sales)
QR кодоор төлсөн:      35,000₮  (qr_sales)
Нийт буцаалтын дүн:   -15,000₮  (return_total)
Нийт зарагдсан чек:    18 ширхэг (sale_count)
```

### Хамгаалалт

- Зөрүүг atomic байдлаар үнэн зөв тооцоолохын тулд `BEGIN IMMEDIATE` транзакцийг ашигладаг
- Системд нэгэн зэрэг зөвхөн нэг л ээлж нээлттэй байх боломжтой бөгөөд давхар ээлж үүсэхээс бүрэн сэргийлсэн

## Аюулгүй байдал / Security

| Хамгаалалтын төрөл | Ажиллагаа ба Тайлбар |
|--------------------|---------------------|
| **CSRF хамгаалалт** | Дата өөрчлөх бүх POST хүсэлтүүд CSRF token шалгана. Token-ийг HTML формоос эсвэл X-CSRF-Token header-ээс уншиж баталгаажуулна |
| **Хүсэлтийн хязгаар (Rate limiting)** | Төлбөр хийх `/api/checkout` хаягт 5 секундэд 10 хүсэлт, баркод унших `/api/barcode`-д 5 секундэд 60 хүсэлтээс илүү гаргахгүй блоклно |
| **SQL Injection хамгаалалт** | Бүх query parameterized (хувьсагчдыг тусад нь дамжуулах). String залгаж query үүсгэхийг хориглосон |
| **XSS халдлагын хамгаалалт** | Орж ирж буй бүх текстийг `escapeHtml()` функцээр sanitize хийж, хортой JS код ажиллахаас сэргийлнэ |
| **Нууц үгийн хамгаалалт** | bcrypt алгоритмаар hash-лэнэ (боломжгүй үед SHA-256 + salt) |
| **Secret key үүсгэлт** | `.env` файлаас унших, байхгүй бол `secrets.token_hex(32)` автомат үүсгэнэ |
| **Session хамгаалалт** | `SESSION_COOKIE_HTTPONLY=True`, `SESSION_COOKIE_SAMESITE=Lax` |
| **Файл upload хязгаар** | `MAX_CONTENT_LENGTH=10MB`. Зөвхөн PNG, JPG, GIF, WebP. UUID нэр өгнө |
| **Цахилгаан тасралт** | `synchronous=FULL` — гэнэт тог тасрахад бааз эвдрэхээс хамгаална |
| **Үнийн луйврын эсрэг** | Хэрэглэгчийн илгээсэн үнийг DB дахь бодит үнээр сервер дээр дахин тулгаж, BEGIN IMMEDIATE транзакц дотор баталгаажуулна |
| **Давхар буцаалт** | `return_of_sale_id` шалгалт транзакц дотор atomic хийгдэнэ |
| **Давхар борлуулалт** | Idempotency key — сүлжээ тасрахад давхар гүйлгээ үүсгэхгүй, хуучин хариуг буцаана |
| **Сангийн бүрэн бүтэн байдал** | Програм эхлэх бүрт `PRAGMA integrity_check` ажиллана |

## Docker / Headless Server

Docker орчинд програм ажиллах үед Desktop цонх нээгдэхгүй бөгөөд зөвхөн вэб интерфейс (Flask + Gunicorn) ажиллана. Хэрэглэгчид сүлжээгээр `http://<сервер-IP>:8765` хаягаар ПОС систем рүү хандах боломжтой.

```bash
# Docker image бүтээх
docker build -t pos .

# Контейнерыг background-д ажиллуулах
docker run -d \
  --name minii-delguur \
  --restart unless-stopped \
  -p 8765:8765 \
  -v /path/to/data:/app/data \
  -v /path/to/backups:/app/backups \
  pos
```

- **Python**: 3.12-slim-bookworm
- **WSGI**: Gunicorn — 2 workers, 4 threads, 120s timeout
- **Хадгалах**: `/app/data` (pos.db), `/app/backups` (нөөц хуулбар)

## Алдаа засах / Troubleshooting

### "Port 8765 is already in use" / Порт ашиглагдсан байна

Програмын өмнөх процесс арын горимд дутуу хаагдаж үлдсэн байна. Компьютерээ restart хийх эсвэл Task Manager-ээс Python процессыг хаана уу. (Linux дээр: `lsof -i :8765` ашиглан процессыг олж устгах).

### Desktop дээрх дүрс ажиллахгүй байна

- **Ubuntu**: Дүрс дээр баруун товч дараад "Allow Launching" (Ажиллуулахыг зөвшөөрөх) сонголтыг идэвхжүүлнэ
- **Windows**: Антивирус програм хаасан байж болзошгүй тул `windows\start.bat` файлыг шууд админ эрхээр ажиллуулж үзнэ

### Дулааны хэвлэгч (Printer) хэвлэхгүй байна

- **Linux**: Портын эрхийг шалгах: `ls -l /dev/usb/lp*`. Хэрэглэгч `lp` группд байгаа эсэхийг харах. Эрх нээх: `sudo chmod 666 /dev/usb/lp0`
- **Windows**: Device Manager → Ports (COM & LPT) хэсэгт үүссэн COM портын дугаарыг харж, програмын Тохиргоо хуудсанд гараар оруулах (Жишээ нь: COM3)

### Үйлчлүүлэгчийн дэлгэц хоёр дахь монитор дээр гарахгүй байна

Эхний удаад үйлчлүүлэгчийн цонхыг гараар хоёр дахь монитор руу чирч байрлуулан томруулна уу. Систем дараагийн удаа асахдаа тухайн байрлалыг автоматаар санах болно.

### Өгөгдлийн сан түгжигдсэн / Database locked

Програмаа restart хийх. WAL mode түгжээнээс хамгаална.

### eBarimt илгээгдэхгүй байвал

- Тохиргоо хуудас → eBarimt тохиргоо шалгах
- Sales History → eBarimt retry товч дарах
- Интернэт холболт шалгах
